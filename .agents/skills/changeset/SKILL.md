# Changeset

Read package metadata, changeset configuration and CONTRIBUTING. Use one entry for the complete consumer-visible change. Before 1.0, breaking changes use a minor bump, identify incompatible calls or data and provide no migration or compatibility layer. Documentation-only changes need no release unless they change a public contract.

Compare the entry with the full diff. Run required checks. Exclude credentials, provider identifiers and personal data.
